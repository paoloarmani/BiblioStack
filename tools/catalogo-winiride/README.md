# Convertitore del catalogo WinIride

`converti.py` trasforma l'export XML di WinIride (`SCUOLE.XML`) in uno script SQL per BiblioStack, più
CSV di revisione ed elenco delle anomalie.

Istruzioni complete: [docs/catalogo-storico.md](../../docs/catalogo-storico.md).

I dati (XML, SQL, CSV, cache) **non vanno nel repository**: il `.gitignore` di questa cartella li esclude.
